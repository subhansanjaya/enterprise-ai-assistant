# Payment Gateway Intermittent Failures

Document ID: INC-2025-001
Document Type: incident
Department: payments
Access Level: internal
Created Date: 2025-02-14

## Summary

On 14 February 2025, the CommercialBank payment gateway experienced
intermittent transaction failures affecting card and online payment
processing.

## Impact

Approximately 18% of payment transactions failed or experienced
significant delays during the incident window.

The incident affected the payment processing API and downstream
merchant integrations.

## Root Cause

The primary root cause was database connection pool exhaustion.

A sudden increase in transaction volume caused the payment service
to consume available database connections faster than they could
be released.

The connection pool configuration was insufficient for the observed
peak workload.

## Resolution

The operations team increased the database connection pool capacity
and restarted affected payment service instances.

Transaction processing returned to normal after the connection pool
was expanded.

## Preventive Actions

- Review database connection pool configuration.
- Add monitoring for connection pool utilization.
- Define alerts for sustained connection exhaustion.
- Perform load testing against expected peak transaction volumes.
