# Payment API Database Connection Incident

Document ID: INC-2025-017
Document Type: incident
Department: payments
Access Level: internal
Created Date: 2025-05-22

## Summary

The payment API experienced elevated error rates during a period of
increased transaction volume.

## Impact

Payment authorization requests experienced elevated latency and
intermittent failures.

## Root Cause

Database connection exhaustion caused requests to queue while waiting
for available database connections.

The payment API was operating with a connection pool configuration
that was below the recommended capacity for peak transaction volume.

## Resolution

The database connection pool was increased and additional monitoring
was enabled.

The affected API instances were restarted to clear stalled database
connections.

## Preventive Actions

- Increase connection pool capacity.
- Monitor active and idle database connections.
- Add alerts for connection pool saturation.
- Review capacity requirements during quarterly performance testing.
